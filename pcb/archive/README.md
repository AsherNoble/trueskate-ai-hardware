# Historical PCB work

These files are retained for reference and rollback. Start with [the current PCB](../README.md).

| Folder | Historical material |
|---|---|
| `four-layer/` | Superseded layer plots, review results and conversion scripts. |
| `copper-evaluation/` | Stopped four-layer copper calculations, geometry, quote and scripts. Results are recorded in [copper-options.md](../../docs/pcb/copper-options.md). |
| `ipc2152-review/` | Technical paper and provenance used in that evaluation. |
| `jlc-four-layer/` | Earlier two-/four-layer 2 oz quotes and stackup references. |
| `fabrication/` | Old manufacturing snapshots; these predate the current footprint/layout. |
| `mockups/` | Earlier assembly concepts and Blender work. |

Archived scripts describe the old directory layout and board revisions. To
reproduce their original environment, use a separate checkout at `88ce19d` (or
`62ef1ea` for the four-layer design). They are not part of the current build or
validation workflow. Copper/thermal qualification remains stopped.
